## 1. Milestone Overview

**Version 2** marks the transformation of EBasura through the integration of **emerging multimodal generative AI technology**. Integrating the Google Gemini REST API (`gemini-2.5-flash` and `gemini-flash-latest`), EBasura introduces automated waste scanning, real-time recyclability and segregation classification, gamified point incentives, and visual prompt injection defenses.

---

## 2. Emerging Technology Capabilities

### Module 3: AI Waste Scanning & Multimodal Classification
- **Google Gemini REST API Integration**:
  - `gemini-2.5-flash`: Lightweight multimodal inference for guest scans and revalidation.
  - `gemini-flash-latest`: High-throughput scanner for authenticated users.
- **5-Attribute Automated Evaluation Contract**:
  - `valid_waste_image`: Confirms whether the captured image contains genuine waste.
  - `recyclable`: Detects plastic bottles, aluminum, cardboard, and recyclable items.
  - `segregated`: Evaluates whether waste is sorted or mixed with other refuse.
  - `biodegradable`: Determines organic decomposition capacity.
  - `non_biodegradable`: Flags synthetics, plastics, and non-decomposing items.
- **Visual Prompt Injection Defense Shield**:
  - Analyzes visible text in captured photos.
  - Mitigates handwritten or printed adversarial prompt override attacks.
  - Automatically overrides all outputs to `false` and quarantines the submission if an injection attempt is detected.
- **Role-Separated Scan Endpoints**:
  - `ScanapibyauthenticatedUserCall`: Awards points and writes to database.
  - `GuestScanCall`: Ephemeral scan allowing non-logged in visitors to try the AI classifier.
  - `RevalidationScanCall`: Secondary audit endpoint for disputed classifications.

### Module 4: Filtered Moderation & Feed Routing
- Automated categorization feeds: AI Classified, Segregated, Unsegregated, Verified, and Uncategorized.
- Quarantined Flagged Images feed (`p_images_view_all_flagged`) for administrative audit of prompt injection attempts.

### Module 5: Gamification, Points Ledger & Badges
- Dynamic point awarding: Points granted automatically upon positive AI classification.
- Community Leaderboard: Live ranked podium powered by accumulated waste classification points.
- Milestone badge unlocking based on recycling actions.
