# EBasura Release Notes — v1.0.0+1 (Version 1)

- **Release Version**: `1.0.0+1`
- **Release Milestone**: **Version 1 — Initial Core Application (Pre-Emerging Technology)**
- **Release Date**: 2026-07-01
- **Target Platform**: Android (Standalone APK Sideload)
- **SDK Compatibility**: `minSdkVersion 23` (Android 6.0 Marshmallow), `targetSdkVersion 36`
- **Distribution Model**: Direct Offline APK Sharing

---

## 1. Milestone Overview

**Version 1** represents the initial operational baseline of EBasura prior to the introduction of emerging artificial intelligence technologies. This version establishes the foundation for civic waste management, user authentication, manual waste reporting, and street collection schedules.

---

## 2. Capabilities & Included Modules

### Module 0: Foundational Presentation & Backend
- FlutterFlow UI engine setup and initial design token palette.
- Supabase initialization (`url`, `anonKey`) connecting to remote PostgreSQL database.
- Initial data models: `user`, `user_subtable`, `street`, `collection`, `report`, and `image`.

### Module 1: Authentication & Access Control
- Email/password user registration and account creation.
- 6-digit OTP email verification flow via Supabase Auth.
- Standard sign-in, session recovery, and password reset flows.
- Guest entry mode allowing read-only access to community feeds and schedules.

### Module 2: User Account & Profile Settings
- User profile dashboard displaying account metadata.
- Display name and profile avatar customization.
- Security credentials management: Change email and change password.

### Modules 6–8: Community Waste Coordination (Manual)
- **Waste Incident Reporting**: Submission of manual waste incident reports with photo uploads and street assignment.
- **Collection Schedules**: Timetable directory displaying scheduled pickup times and assigned collectors for registered streets.
- **Street Directory**: Community street registry serving as the foreign-key link for municipal operations.

### Module 9: Administrator Console (Initial)
- Central dashboard displaying system counters (total users, registered streets, active schedules).
- Basic user management table and account status controls.

---

## 3. Architecture State
- **AI Classification**: *Not yet integrated*. Waste images served as static manual proof of dumping or reports.
- **Offline Packaging**: Initial build scripts without automated versioning or checksum manifests.
