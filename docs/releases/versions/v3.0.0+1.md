## 1. Milestone Overview

**Version 3** establishes the complete architecture and release infrastructure for EBasura in its current state. It unites the core civic waste management features of Version 1 and the Gemini AI vision engine of Version 2 with a 11-module technical documentation framework, a sprint backlog catalog, and an automated offline APK packaging and distribution skill suite.

## 2. Included Capabilities & New Features

### 1. Complete Modular Documentation Architecture (`docs/modules/`)
- Exhaustive documentation across all 11 core system modules:
  - **Module 0**: Core Architecture, Setup & State Management
  - **Module 1**: Authentication, Identity & Security
  - **Module 2**: User Profile & Account Management
  - **Module 3**: AI Waste Scanning & Classification
  - **Module 4**: Waste Records, Inspection & Moderation
  - **Module 5**: Gamification, Points System & Badges
  - **Module 6**: Waste Reporting & Community Alerts
  - **Module 7**: Garbage Collection Schedules
  - **Module 8**: Street & Community Directory
  - **Module 9**: Administrator Operations & User Management
  - **Module 10**: Navigation & Shared Components
- Each module directory features an introductory `README.md` with a tabular feature matrix accompanied by granular submodule technical specifications.

### 2. Sprint Backlogs & Canonical Commit Reference
- [`docs/backlogs/EBASURA_Sprint_Backlogs_Commit_Reference.md`](../backlogs/EBASURA_Sprint_Backlogs_Commit_Reference.md): Canonical catalog establishing the mandatory commit grammar:
  ```text
  <type>(<scope>): <concise description in past-tense> [EBASURA-M#-F#]
  ```
- Exhaustive index mapping every feature code (`EBASURA-M0-F0` through `EBASURA-M10-F4`).

### 3. Offline APK Release & Distribution Suite (`.agents/skills/apk-release/`)
- Dedicated **`apk-release`** agent skill for offline distribution without app store reliance.
- Companion automation runner (`build_apk_release.py`):
  - Automates semantic versioning and build number management in `pubspec.yaml`.
  - Compiles release APK with embedded environment constants: `flutter build apk --release --dart-define-from-file=env.json`.
  - Archives standalone APK to local repository folder: `releases/v<version>/EBasura-v<version>-release.apk`.
  - Calculates file size and SHA-256 integrity checksums.
  - Generates version documentation in `docs/releases/versions/` and updates the master release catalog.
- Repository safety: Configured `.gitignore` to prevent binary APK files from bloating Git history.

### 4. Developer Agent Skills Suite
- **`git-commits`**: Backlog-linked conventional commits enforcing `[EBASURA-M#-F#]` tags.
- **`staging-readiness-audit`**: Pre-flight audit verifying clean Git drift, secret protection (`env.json`), and static analysis.
- **`pr-check-fix`**: Automated diagnosis and patch generator for analyzer, formatting, and test failures.
- **`project-verification`**: Flutter verification pipeline (`flutter analyze`, `flutter test`).
- **`workspace-onboarding`**: Session bootstrap and environment pre-flight validator.

## 4. End-User Installation & Sideloading
1. Transfer `EBasura-v3.0.0+1-release.apk` from `releases/v3.0.0+1/` to an Android phone.
2. Tap the APK file in **Files** or **Downloads**.
3. Toggle **Allow from this source** if prompted.
4. Select **Install** (or **Install anyway** if prompted by Google Play Protect).
5. Launch the application and grant Camera permission.
